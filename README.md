# FSEA -Emotion Analysis Enhancement with Fuzzy Signature 
In this study, we introduced a hybrid fuzzy signature-based approach to ana-lyze and model emotions derived from Plutchik wheel of emotions. The Fuzzy Signature Emotion Analysis (FSEA) model was illustrated on love as a complex emotion derived from six key sub-emotions: serenity, joy, ecstasy, acceptance, trust, and admiration. Then, we aggregated different tree structures (observa-tions) to accommodate for potential discrepancies in human judgments (annota-tions). Using fuzzy signature sets, we captured the overlapping nature of the sub emotions embedded in textual data, allowing smooth transitions (and better rep-resentation) between different levels of emotional intensity.
We applied and extended the FSEA model on all emotions spectrum (Plutchik wheel) using Mamdani inference system integrated with Emotion Distribution Learning. The FSEA model was utilized to generate a labeled dataset, tested and compared with Twitter Emotion Corpus on Bidirectional Long Short-Term Memory (BiLSTM) and Bidirectional GRU (Gated Recurrent Unit) models for emotion detection. Moreover, the FSEA showed good results with transformer-based models. 
Indeed, the FSEA exhibits the ability to capture the ingrained ambiguity in tex-tual emotional states and improved emotion labeling. We are eager to enhance the FSEA’s results with transformer-based model and extend this study in senti-ment analysis and fraud detection where accurately detecting emotional state is vital.

## Problem Formulation
Humans express their emotions by words. Emotion analysis is a method to identify emotional status. Emotion Distribution Learning (EDL) analysis and translates human emotions with multiple intensities conveyed in data. Gener-ally, emotion detection and classification from text is a more complex task than just labeling it under six categories: love, fear, joy, sadness, surprise and anger. Indeed, human emotions form a complex, interconnected spectrum as presented in Plutchik wheel of emotions. In this paper we propose a hybrid emotion analysis model; the Fuzzy Signature Emotion Analysis (FSEA). In-tegrated with the classical EDL approach, the FSEA facilitates Fuzzy Signa-ture (FSig) inference system to dynamically construct structural trees from text, based on Plutchik wheel of emotions. We applied FSEA framework on textual data (tweets) to extract the embedded emotional cues and generated a highly grained labeled dataset. Finally, we applied two state-of-the-art emo-tion classification models; Bidirectional Long Short-Term Memory (BiLSTM) and Bidirectional GRU (Gated Recurrent Unit) on TEC (Twitter Emotion Corpus) and the FSEA’s generated labeled dataset. The results show more efficient detection of the overlapping implicit and explicit emotion cues by the FSEA model with high accuracy, precision and F1 score.
